# Unified-mentor-Digital-Marketing
This project provides a comprehensive website redesign plan and a digital marketing strategy for Mahendra's Educational Private Limited. The goal is to modernize their online platform and turn their massive free Google search traffic into active online course sales.
What is inside this repository:
1. Website Redesign Proposal (PDF): An audit of the current website's mobile and desktop issues, along with a plan to split the site into 3 clean sections: Learning, Practice, and Updates.
2. Digital Marketing Strategy Document (PDF): A step-by-step growth plan covering Google and Instagram marketing, SEO keyword optimization, and automated WhatsApp/email systems to nurture leads.
3. Mahendras ppt (Presentation): The summary slide deck showing visual comparisons of the old website versus the new layout, alongside the 10-week launch timeline.
